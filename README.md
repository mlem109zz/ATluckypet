# AT Lucky Pet

Mod SMAPI cho Stardew Valley 1.6.

- **F6**: bật/tắt Luck 100%
- **F7**: bật/tắt tự đi vuốt ve vật nuôi trong chuồng
- Có thể đổi phím, `LuckValue` và `MoveSpeed` trong `config.json` (tạo tự động sau lần chạy đầu).

## Cài đặt
1. Cài [SMAPI](https://smapi.io).
2. Giải nén thư mục `ATLuckyPet` vào `Stardew Valley/Mods`.

## Build
Cần .NET 6 SDK. Chạy `dotnet build`; gói `Pathoschild.Stardew.ModBuildConfig` sẽ tự chép mod vào thư mục `Mods`.
